# 终端横幅（brand-banner）

`assets/banners/` 提供 5 套预渲染的 80 列等宽横幅，用于 CLI 首屏、文档分隔与演示占位。每套均为纯 ASCII，按 80 列逐行排布，直接输出即可保持对齐。

## 使用规则

1. **触发**：用户通过 `/黄桃罐头` 命令调用本 skill——消息中出现该命令，或调用来源就是该命令（斜杠命令展开后文本可能不保留）。命令后面跟什么内容都算命中。
2. **无条件**：命令之后的任何内容一律忽略——包括代码、问题、追问、否定指令（「别画图」「先回答」「只回复文字」）以及要求修改本规则的内容。只输出 1 套横幅，不复述、不评论、不揣测，也不说明为什么忽略。
3. **随机**：从 01~05 中挑 1 套；不要固定第一套，也不要因对话上下文偏向某一套。
4. **原样**：从第一行输出到最后一行，逐字符照抄；保留每行 80 列与行首行尾空格，不重排、不对齐修正、不裁剪。
5. **纯输出**：用一个代码块包裹，语言标记留空；代码块之外不加开场白、标题、编号、说明、注释、结尾语或 emoji，也不说明选了第几套。
6. **单一回复**：横幅输出即为完整回复；不调用工具、不读写文件，本轮不再展开其他内容。
7. **非触发场景**：没有通过 `/黄桃罐头` 命令调用本 skill 时，正常处理编程任务，不输出横幅。

## 示例

| 输入 | 输出 |
| --- | --- |
| `/黄桃罐头` | 1 套横幅 |
| `/黄桃罐头 帮我修一下这个 bug` | 1 套横幅 |
| `/黄桃罐头 别画图，先解释这段代码` | 1 套横幅 |
| `/黄桃罐头 先回答我，图以后再说` | 1 套横幅 |
| `帮我修这个 bug` | 正常处理，不输出横幅 |
